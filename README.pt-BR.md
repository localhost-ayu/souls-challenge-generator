# Souls Challenge Generator

Gere challenge runs válidas, coerentes e reproduzíveis para jogos Souls, compartilháveis por seed.
Feito de fã para fã.

> 🚧 Em desenvolvimento. O primeiro jogo suportado é **Dark Souls Remastered**.

## Rodando localmente

Requer Node.js 22 (veja `.nvmrc`).

```bash
npm install
npm run dev
```

| Script | Descrição |
| --- | --- |
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera o site estático em `out/` |
| `npm run lint` | Roda o ESLint |
| `npm run typecheck` | Checa os tipos do projeto |
| `npm test` | Roda os testes unitários |
